# Card Battler | Unity & C#

## A strategic 2D card battler built in Unity and C#, featuring deck building, turn-based combat, animated boss battles, and unique attack and healing cards.

My 2D Card Battler is a strategic turn-based game developed in Unity using C#. Players build a custom deck and use attack, double-attack, and healing cards to defeat an animated boss while managing their health and available cards. The project features custom systems for deck building, drawing and discarding cards, turn management, combat, health, audio, animations, and UI management. I followed a card battler course to strengthen my understanding of Unity and event-driven game development. This project also gave me hands-on experience with ScriptableObjects, C# events, coroutines, scene management, and modular gameplay systems.

* Strategic turn-based card combat
* Custom deck-building system
* Attack, double-attack, and healing cards
* Card drawing, discarding, and deck reshuffling
* Animated player and boss combat
* Player and enemy health systems
* Event-driven gameplay architecture
* Custom turn-management system
* Interactive card hover and selection effects
* Sound effects and audio management
* Victory and defeat conditions
* Menu and scene management

## How to install

Download Card Battler Course here: jarelhearst.itch.io/card-battler-course

Installation
* Visit the Card Battler itch.io page using the link above.
* Click the Download button.
* Download the game files to your computer.
* Extract the downloaded .zip file.
* Open the extracted folder.
* Double-click the game's .exe file.
* Start playing! 🎮

Windows: If Windows displays a security warning, select More info → Run anyway if you trust the download.
